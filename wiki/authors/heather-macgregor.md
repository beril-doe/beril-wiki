# Heather MacGregor

## Contributions

[[summaries/metal_resistance_global_biogeography__REPORT]] extracted 260,652 environmental MAGs (metagenome-assembled genomes) from MGnify, kept 30,497 after filtering host-associated biomes, and found usable coordinates for 22,356 of them (73.3% coverage) [src: metal_resistance_global_biogeography]. It found that 2.8% of the coordinate-bearing MAGs carried at least one metal-resistance type [src: metal_resistance_global_biogeography]. A 5° grid analysis of 289 cells, each with at least 5 MAGs, used Fisher's exact tests with Benjamini–Hochberg false discovery rate correction and identified 11 significant hotspots (odds ratio, OR>2, and FDR-adjusted q<0.05) and 3 coldspots (OR<0.5, q<0.05) [src: metal_resistance_global_biogeography]. The top hotspot was the Atacama/Andean region of Chile (21.8% prevalence, OR=9.83, q=7.6e-12, n=101 MAGs) [src: metal_resistance_global_biogeography]. The project found soil enriched for metal resistance (5.8%, OR=5.05, q=1.8e-82), found marine samples depleted (1.2%, OR=0.20, q=9.2e-80), and reported a non-significant rhizosphere result (1.9%, OR=0.66, q=0.30) [src: metal_resistance_global_biogeography]. It found a 30.8% per-sample ENA coordinate gap, with only 16,964 of 24,511 records having valid coordinates, but 0 of 532 MAG grid cells lacked coverage [src: metal_resistance_global_biogeography]. The report is preliminary, and its tests for sampling effort and single-study artefacts in the hotspots have not been run [src: metal_resistance_global_biogeography].

[[summaries/t4ss_cazy_environmental_hgt__REPORT]] found type IV secretion system (T4SS) or conjugative machinery in 6,652 of 30,497 high-quality environmental MAGs (21.8%) [src: t4ss_cazy_environmental_hgt]. It also found 92 carbohydrate-active enzyme (CAZy) families with elevated co-occurrence at ≤10 kb from T4SS loci, with GT2 glycosyltransferases as the top hit; threshold validation for these co-occurrences is still pending [src: t4ss_cazy_environmental_hgt]. The project detected 77 horizontal gene transfer (HGT) events in the GT2 gene tree, including 32 high-confidence cross-phylum events, and the strongest, Node_4915, spans 8 phyla [src: t4ss_cazy_environmental_hgt]. Divergence and synteny across these events were negatively correlated (Spearman ρ = −0.615, p<0.001) [src: t4ss_cazy_environmental_hgt]. ICEfinder detected no plasmid-borne CAZy genes, and T4SS-positive genomes had 10× higher mobile-element density, which the project read as consistent with chromosomal or integrative transfer [src: t4ss_cazy_environmental_hgt]. GT2-neighborhood MAGs (n=376) carried a mean of 0.045 metal-resistance types versus 0.004 for non-GT2 MAGs (n=260,276; Mann–Whitney p=8.6e-27) [src: t4ss_cazy_environmental_hgt]. The report states that all of these associations are observational and require experimental validation [src: t4ss_cazy_environmental_hgt].

[[summaries/soil_metal_functional_genomics__REPORT]] identified 2,355 significant COG–metal associations at FDR < 0.05 across nine metals and 51,748 soil samples; a COG is a Cluster of Orthologous Groups functional category, and FDR is the false discovery rate [src: soil_metal_functional_genomics]. The report states that these associations are observational and that effect sizes have not been systematically reported, so statistical significance may not imply substantial biological effect [src: soil_metal_functional_genomics]. It found a db-RDA R² = 0.799 (p = 0.005), conditional on project effects; db-RDA is a constrained ordination of a distance matrix [src: soil_metal_functional_genomics]. The project cautioned that the unconditional R² was not reported and that metal co-contamination may make the FDR anti-conservative [src: soil_metal_functional_genomics]. [[summaries/soil_frontier_genomics__REPORT]] tested the clay shield hypothesis on 5,441 soil samples and found negative out-of-sample R² for all model families [src: soil_frontier_genomics]. It found no significant difference between high-clay and low-clay soils (difference 0.024, 95% CI: −0.423, 0.161), so the hypothesis was not supported at global scale [src: soil_frontier_genomics]. The report notes that it has not yet separated modelling failure from genuine unpredictability [src: soil_frontier_genomics]. Its Genomic Discovery Index ranked forest (902.36) and cropland (890.82) as jointly highest, though the report flags the index as novel and lacking bootstrap confidence intervals [src: soil_frontier_genomics]. The report also cautions that the index conflates sampling gap and OTU richness, so the richness term may dominate, and that it can equal 902 even when there are zero genomes [src: soil_frontier_genomics]. It found a +0.8 pH unit gap between frontier areas and mapped areas, but the report states that controlling for the number of 16S samples per pH bin is still required to distinguish a sampling gap from an assembly or annotation gap [src: soil_frontier_genomics].

[[summaries/microbeatlas_metal_ecology__REPORT]] found strong phylogenetic signal in bacterial niche breadth (Pagel's λ = 0.787, p = 7.9×10⁻¹⁰²) across 1,264 genera [src: microbeatlas_metal_ecology]. In PGLS (a regression that accounts for shared ancestry) across 606 genera, metal type diversity was the only metal AMR (antimicrobial resistance, here from AMRFinderPlus annotations) predictor surviving Bonferroni correction (β = +0.021, SE = 0.0056, p = 1.5×10⁻⁴) [src: microbeatlas_metal_ecology]. Total AMR cluster count and core AMR fraction were not significant in that analysis [src: microbeatlas_metal_ecology]. The project found that metal type diversity did not predict the number of environments detected (p = 0.923) [src: microbeatlas_metal_ecology]. Its strict 5% prevalence sensitivity analysis was not significant (p = 0.092), and none of the 7 leave-one-metal-out exclusions stayed significant [src: microbeatlas_metal_ecology]. The report treats the association as correlational, with its causal direction undetermined [src: microbeatlas_metal_ecology].
