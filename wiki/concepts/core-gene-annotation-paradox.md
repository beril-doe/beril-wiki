# Conserved Core Genes Can Remain Structurally and Functionally Uncharacterized

Core classification indicates broad pangenome conservation, but it does not guarantee that a gene has substantial representation in characterized sequence space or a well-defined molecular function. The [alphafold_msa_annotation__REPORT](../summaries/alphafold_msa_annotation__REPORT.md) examines this distinction by relating pangenome gene-cluster classes to AlphaFold multiple-sequence-alignment (MSA) depth, where MSA depth is the number of homologous sequences represented in the alignment. [^alphafold_msa_annotation] Evidence from [core_gene_tradeoffs__REPORT](../summaries/core_gene_tradeoffs__REPORT.md) **refines** this distinction: core genes can be functionally active and conditionally costly in laboratory assays while still being structurally or functionally uncharacterized. [^core_gene_tradeoffs] The [conservation_fitness_synthesis__REPORT](../summaries/conservation_fitness_synthesis__REPORT.md) **supports** this interpretation across 194,216 protein-coding genes from 43 bacteria: essential genes were 82% core, but genes neutral in every experiment were still 66% core, showing that conservation and measured fitness importance are related but non-equivalent. [^conservation_fitness_synthesis] The new [fitness_effects_conservation__REPORT](../summaries/fitness_effects_conservation__REPORT.md) **supports** this distinction across approximately 194,000 genes from 43 bacteria: essential genes were 82% core, whereas always-neutral genes were 66% core, so laboratory fitness importance was a statistically robust but weak predictor of conservation. [^fitness_effects_conservation] Evidence from [module_conservation__REPORT](../summaries/module_conservation__REPORT.md) **supports** the conservation side of this distinction: co-regulated fitness-module genes were 86.0% core versus 81.5% for all genes, although this enrichment does not establish that the genes are functionally characterized. [^module_conservation]

## Core Genes Usually Have Greater Sequence Representation

Among gene clusters bridged to AlphaFold, core clusters had a median MSA depth of 15,308, compared with 5,299 for auxiliary+singleton clusters and 5,527 for auxiliary non-singleton clusters. [^alphafold_msa_annotation] This corresponds to a 2.89× higher median for core genes than auxiliary+singleton genes and a 2.77× higher median than auxiliary non-singleton genes. [^alphafold_msa_annotation] The 10th-percentile MSA depth was 334 for core genes versus 25–32 for accessory classes. [^alphafold_msa_annotation]

These distributions are consistent with a broad class-level annotation advantage for core genes, but they do not eliminate poorly represented core proteins. Among bridged clusters, 415,733 core clusters (1.6%) had MSA depth below 10, compared with 245,002 auxiliary non-singleton clusters (4.6%) and 392,959 auxiliary+singleton clusters (5.5%). [^alphafold_msa_annotation] The fitness analysis **supports** treating this annotation advantage as distinct from functional importance: core genes were more burdensome in several functional categories, but this does not establish that their molecular functions are characterized. [^core_gene_tradeoffs] The broader synthesis **refines** this point: core genes were 1.78x more likely than accessory genes to have strong condition-specific phenotypes, so detectable laboratory activity does not make their molecular roles fully characterized. [^conservation_fitness_synthesis] The new fitness analysis **supports** this refinement: strong condition-specific effects occurred in 77.3% of core genes versus 70.3% of genes without such annotations, and core genes were more likely than auxiliary genes to show benefits as well as costs, indicating measured activity without implying complete annotation. [^fitness_effects_conservation] The module analysis **refines** this interpretation by showing that conservation also extends to co-regulated units: 577 of 974 mapped modules (59%) were >90% core, while 38 module families had <50% core genes. [^module_conservation] A separate ICA synthesis identified 1,116 co-regulated fitness modules across 32 organisms, with 86% core genes versus an 81.5% baseline (odds ratio 1.46, p=1.6e-87), **supporting** coordinated conservation without implying complete functional annotation. [^conservation_fitness_synthesis]

## A Conserved Low-MSA Core Subset

The analysis identified 415,603 distinct core clusters with MSA depth below 10 across 14,768 species clades. [^alphafold_msa_annotation] Their mean MSA depth was 4.57 and their median MSA depth was 4.0. [^alphafold_msa_annotation] Of these clusters, 286,439 (68.9%) were annotated as hypothetical, 137 (0.033%) had an EC annotation, and 346 (0.083%) were mapped to KEGG. [^alphafold_msa_annotation]

The low-MSA core subset therefore had a 68.9% hypothetical-protein rate, whereas all bridged core genes had a 3.8% hypothetical-protein rate. [^alphafold_msa_annotation] This contrast supports the interpretation that pangenome conservation and functional characterization measure different properties: a gene can be retained broadly while remaining distant from experimentally or computationally characterized sequence space. [^alphafold_msa_annotation] The trade-off analysis **supports** the complementary claim that conservation can reflect active, condition-dependent function rather than annotation completeness: 25,271 genes were classified as true trade-off genes, and trade-off genes were 1.29 times more likely to be core than non-core genes (odds ratio 1.29, p=1.2e-44). [^core_gene_tradeoffs] The synthesis further identifies 28,017 genes that were both costly in the laboratory and conserved, but treats this category as evidence for possible purifying selection rather than direct measurement of natural selection. [^conservation_fitness_synthesis]

The report treats these proteins as candidates for experimental structural characterization, rather than as experimentally validated examples of novel function. [^alphafold_msa_annotation] The prioritization hypothesis is strongest for proteins that are conserved by pangenome classification but have very shallow alignments and little EC, KEGG, or domain-level annotation. [^alphafold_msa_annotation] The fitness analysis **refines** this prioritization logic: novel singleton genes showed near-zero mean fitness in tested laboratory conditions, but that apparent neutrality may reflect poor transposon coverage rather than absence of biological function. [^fitness_effects_conservation]

## Functional Annotation Tracks MSA Depth

Across 38,051,842 gene cluster–UniProt pairs, MSA depth and domain-hit count had a Spearman correlation of ρ = 0.7563. [^alphafold_msa_annotation] Mean domain hits increased from 0.59 for clusters with MSA depth below 10 to 10.83 for clusters with MSA depth of at least 10,000. [^alphafold_msa_annotation] Mean distinct InterPro families increased from 0.059 to 4.601 across the same MSA-depth range. [^alphafold_msa_annotation] The monotone relationship held within core, auxiliary non-singleton, and auxiliary+singleton classes, with core genes showing slightly higher domain richness per MSA bin than accessory genes at equivalent depth. [^alphafold_msa_annotation]

This relationship supports MSA depth as a useful prioritization signal for annotation scarcity, but it does not establish that sequence abundance causes functional knowledge or that shallow MSA depth proves biological novelty. [^alphafold_msa_annotation] Of all 132,531,501 gene clusters, 111,035,431 (83.8%) had at least one InterProScan domain annotation, whereas only 38,804,903 (29.3%) had a real UniProt accession and 38,051,842 (28.7%) bridged successfully to AlphaFold MSA depths. [^alphafold_msa_annotation]

The fitness results **refine** interpretation of the shallow-MSA subset by showing that laboratory burden is also condition- and function-dependent: core genes were more burdensome in Protein Metabolism, Motility, and RNA Metabolism, whereas Cell Wall genes showed the reverse pattern, with non-core genes more burdensome. [^core_gene_tradeoffs] The synthesis quantifies related category-specific contrasts: Motility and chemotaxis had a +7.8pp core-burden excess, RNA metabolism a +12.9pp excess, and protein metabolism a +6.2pp excess, while cell-wall genes again showed the reverse pattern. [^conservation_fitness_synthesis] These measurements indicate functional activity or trade-offs, not verified molecular annotation or direct evidence of natural selection. [^core_gene_tradeoffs]

## Two Annotation-Gap Layers

The evidence distinguishes two related annotation-gap layers. [^alphafold_msa_annotation] First, an MSA-depth-driven gap affects genes in every pangenome class, because domain richness decreases sharply in shallow-MSA bins. [^alphafold_msa_annotation] Second, a pangenome-class gap is visible in the higher hypothetical-protein rates of accessory classes: 13.8% for auxiliary+singleton clusters, 11.6% for auxiliary non-singleton clusters, and 3.8% for core clusters. [^alphafold_msa_annotation]

The class-level comparison is dominated by the higher average MSA depth of core genes, while the low-MSA core subset reveals a severe annotation gap within the core itself. [^alphafold_msa_annotation] This distinction **refines** [pangenome-integration](pangenome-integration.md) by showing that core status should not be treated as a proxy for complete annotation. [^alphafold_msa_annotation] It also **supports** interpreting the costly-and-conserved subset as a functional-prioritization signal rather than as evidence that every conserved gene is already understood: the trade-off study reported 28,017 Costly + Conserved genes, but its selection interpretation rests on laboratory fitness and conservation patterns rather than direct natural-selection measurements. [^core_gene_tradeoffs] The synthesis additionally reports 5,526 genes that were costly and dispensable, treating them as candidates for mobile-element association, recent acquisition, or gene loss rather than as established examples of any one process. [^conservation_fitness_synthesis]

The module analysis **refines** the class-level interpretation by finding no relationship between module-family breadth and conservation (Spearman ρ=-0.01, p=0.914), redirecting attention from the scope of a module family toward gene-level conservation. [^module_conservation] Because ICA requires measurable fitness variation from transposon-insertion data, zero essential genes appeared in the modules; this **supports** treating module conservation as complementary evidence rather than a complete account of conserved functional units. [^module_conservation] The independent synthesis similarly found no module-family breadth gradient (rho=-0.01 and p=0.91), **supporting** the conclusion that coordinated conservation does not by itself resolve annotation status. [^conservation_fitness_synthesis]

## Scope and Interpretation

Only 38,051,842 of 132,531,501 total gene clusters (28.7%) bridged successfully to AlphaFold MSA depths, while 70.7% lacked UniRef100 IDs or had UniParc-only identifiers without an AlphaFold entry. [^alphafold_msa_annotation] Because the analysed subset is biased toward better-studied organisms, the annotation gap among the remaining 70.7% is likely larger, although that inference was not directly measured. [^alphafold_msa_annotation]

MSA depth was obtained for each cluster's representative sequence, so the analysis did not measure sequence-level variation within each cluster. [^alphafold_msa_annotation] The 293K genomes were not phylogenetically balanced, and common taxa such as *Pseudomonas* and *E. coli* were over-represented. [^alphafold_msa_annotation] The reported Spearman ρ = 0.7563 was calculated on the full 38,051,842-pair dataset without subgroup stratification. [^alphafold_msa_annotation] These limitations mean that the low-MSA core set is a defensible discovery and prioritization set, not a complete census of conserved functionally dark genes. [^alphafold_msa_annotation] The trade-off study adds a related limitation: Fitness Browser conditions are biased toward experimentally convenient rather than ecologically representative conditions, so costly core genes cannot by themselves be taken as evidence of selection in nature. [^core_gene_tradeoffs] The synthesis likewise states that laboratory measurements capture gene-maintenance costs while pangenome conservation captures evolutionary retention, not direct natural-environment fitness. [^conservation_fitness_synthesis] The new fitness analysis **supports** this caveat by noting that its assays were biased toward rich media and standard stresses, that measurements used single-gene knockouts without epistatic interactions, and that the 43-bacterium coverage was primarily Proteobacteria. [^fitness_effects_conservation] The module-conservation estimate is likewise limited to a 29/32 organism subset, because three organisms lacked pangenome links. [^module_conservation]

## Open Directions

- Join the 415,603 low-MSA core clusters to [kescience-fitnessbrowser](../entities/kescience-fitnessbrowser.md) measurements and use condition-specific fitness analysis to ask whether structurally isolated core proteins have essential or condition-dependent phenotypes. [^alphafold_msa_annotation]
- Recompute MSA depth and InterPro-family richness after stratifying the 38,051,842 bridged pairs by pangenome class and organismal lineage, using Spearman correlations and balanced taxon sampling to ask whether the ρ = 0.7563 relationship is consistent across taxa. [^alphafold_msa_annotation]
- Compare representative-sequence MSA depths with member-level sequence diversity for the 415,603 low-MSA core clusters, using within-cluster pangenome sequence analysis to ask whether representatives conceal deeper or shallower support among cluster members. [^alphafold_msa_annotation]
- Prioritize the 286,439 hypothetical low-MSA core clusters for structure prediction and experimental characterization, using the 137 EC-annotated and 346 KEGG-mapped clusters as annotated comparators to ask which structural features predict recoverable function. [^alphafold_msa_annotation]
- Extend the bridge analysis to the 70.7% of clusters without AlphaFold MSA depth, using alternative sequence-similarity and domain resources to ask whether the unbridged population contains a larger conserved annotation gap. [^alphafold_msa_annotation]
- Intersect low-MSA core clusters with the 28,017 Costly + Conserved genes and test their fitness across ecologically relevant conditions, asking whether shallow sequence representation predicts condition-dependent burden or essentiality. [^core_gene_tradeoffs]
- Test whether low-MSA core clusters are overrepresented in the 38 accessory module families, and whether module membership or module-family breadth predicts annotation recovery after controlling for pangenome class. [^module_conservation]
- Intersect the low-MSA core set with the 5,526 costly-and-dispensable genes and test mobile-element, acquisition, and gene-loss hypotheses using genomic-context and phylogenetic analyses. [^conservation_fitness_synthesis]
- Intersect low-MSA core clusters with the fitness-effect categories from the 43-bacterium dataset and test whether shallow MSA representation predicts condition-specific burden, benefit, or apparent neutrality after controlling for transposon coverage. [^fitness_effects_conservation]
