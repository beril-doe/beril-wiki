# LpxC

## What this entity is

**Canonical name:** LpxC. [^caulobacter_fur_lipida_loss]

**Known aliases:** LpxC; the source report does not provide an alternative gene symbol or locus identifier. [^caulobacter_fur_lipida_loss]

**Stable external identifier:** No stable external identifier is reported in the source document. [^caulobacter_fur_lipida_loss]

LpxC is a lipid A biosynthesis enzyme whose deletion is viable in the Δfur ΔsspB background of [caulobacter-crescentus](caulobacter-crescentus.md), linking it to the organism’s lipid A-loss rescue phenotype. [^caulobacter_fur_lipida_loss]

## Key facts from the source

The report analyzes how Δfur ΔsspB permits ΔlpxC viability in [caulobacter-crescentus](caulobacter-crescentus.md) while examining Fur regulation, ChvI responses, sphingolipid substitution, outer-membrane transport, and peptidoglycan remodeling. [^caulobacter_fur_lipida_loss]

The report’s comparative PaperBLAST screen returned 0 hits for Caulobacter LpxC, whereas NCBI annotation returned 15 hits. [^caulobacter_fur_lipida_loss]

The discrepancy between the 0 PaperBLAST hits and 15 NCBI hits for LpxC was part of a broader false-negative problem affecting the tested Caulobacter lipid A genes; the report characterizes the tested set as having an approximately 80% false-negative rate. [^caulobacter_fur_lipida_loss]

The report retains the cross-species absence conclusions because they were supported independently by NCBI annotation and literature rather than by PaperBLAST alone. [^caulobacter_fur_lipida_loss]
