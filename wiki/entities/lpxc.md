# LpxC

## What this entity is

**Canonical name:** LpxC. [src: caulobacter_fur_lipida_loss]

**Known aliases:** LpxC; the source report does not provide an alternative gene symbol or locus identifier. [src: caulobacter_fur_lipida_loss]

**Stable external identifier:** No stable external identifier is reported in the source document. [src: caulobacter_fur_lipida_loss]

LpxC is a lipid A biosynthesis enzyme whose deletion is viable in the Δfur ΔsspB background of [[entities/caulobacter-crescentus]], linking it to the organism’s lipid A-loss rescue phenotype. [src: caulobacter_fur_lipida_loss]

## Key facts from the source

The report analyzes how Δfur ΔsspB permits ΔlpxC viability in [[entities/caulobacter-crescentus]] while examining Fur regulation, ChvI responses, sphingolipid substitution, outer-membrane transport, and peptidoglycan remodeling. [src: caulobacter_fur_lipida_loss]

The report’s comparative PaperBLAST screen returned 0 hits for Caulobacter LpxC, whereas NCBI annotation returned 15 hits. [src: caulobacter_fur_lipida_loss]

The discrepancy between the 0 PaperBLAST hits and 15 NCBI hits for LpxC was part of a broader false-negative problem affecting the tested Caulobacter lipid A genes; the report characterizes the tested set as having an approximately 80% false-negative rate. [src: caulobacter_fur_lipida_loss]

The report retains the cross-species absence conclusions because they were supported independently by NCBI annotation and literature rather than by PaperBLAST alone. [src: caulobacter_fur_lipida_loss]
