## Caveat

Abiotic features (pH, temperature, total organic carbon) were all NaN for the 174-sample matrix, preventing partial correlations that control for environmental gradients. [src: nmdc_community_metabolic_ecology]

> Abiotic features (pH, temperature, total organic carbon, etc.) were absent (all NaN) for the 174-sample analysis matrix, preventing partial correlation tests controlling for environmental gradients. These variables could confound both H1 and H2 results. [src: nmdc_community_metabolic_ecology]

- Methionine biosynthesis had the largest reported correlation effect (r = −0.496), but sample size limited significance (n = 18, q = 0.117). [src: nmdc_community_metabolic_ecology]

- Proline was skipped in the NMDC H1 pathway correlation analysis with n = 9. [src: nmdc_community_metabolic_ecology]
