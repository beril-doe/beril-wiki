# Cross-phylum null makes intra-phylum AMR HGT look clumped

The report states that within Pseudomonadota or Bacillota AMR HGT is intense but across phyla it is rare, so a cross-phylum dispersion null makes intra-phylum HGT look clumped. [src: gene_function_ecological_agora]

## Evidence

> Within Pseudomonadota or Bacillota, AMR HGT is intense; across phyla, it is rare. The current null measures cross-phylum dispersion, which makes intra-phylum HGT look "clumped." [src: gene_function_ecological_agora]
