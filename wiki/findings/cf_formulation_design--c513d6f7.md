# Larger formulation sizes are statistically indistinguishable on composite score

All k=2 through k=5 bootstrap confidence intervals overlap, so formulation sizes are not statistically distinguishable on the composite score, which the report uses to support k=2 as the practical primary candidate. [src: cf_formulation_design]

## Evidence

> All k=2 through k=5 CIs overlap — formulation sizes are **not statistically distinguishable** on the composite score, supporting the recommendation of k=2 as the practical primary candidate (see §3.2). [src: cf_formulation_design]

From the report [[summaries/cf_formulation_design__REPORT]].

## Caveat

Pairwise interactions rest on only 8 comparisons across 5 unique pairs, so the additive scoring assumption should be treated as provisional until the full 10-pair matrix is measured. [src: cf_formulation_design]

> **Conclusion**: Pairwise interactions are approximately additive for *N. mucosa* combinations, supporting its role as a formulation anchor. However, these conclusions are based on only **8 comparisons across 5 unique pairs** — an underpowered sample. The complete 10-pair interaction matrix for the 5-species core (Proposed Experiment 4.2) is a critical gap, not merely a nice-to-have extension. Until the full matrix is measured, the additive scoring assumption should be treated as provisional. [src: cf_formulation_design]
