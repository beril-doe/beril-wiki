# UniRef50 clumping weakens at class rank, suggesting cross-class HGT

The report interprets UniRef50 dispersion approaching the random-permutation null at class rank as consistent with cross-class HGT becoming detectable above noise, while vertical inheritance dominates genus through order. [src: gene_function_ecological_agora]

## Evidence

> This is the first interpretable biological pattern in the atlas: **at class rank, UniRef50 dispersion approaches the random-permutation null** — consistent with cross-class HGT becoming detectable above noise. At deeper ranks (genus through order), vertical inheritance dominates as expected. [src: gene_function_ecological_agora]

From the report [[summaries/gene_function_ecological_agora__REPORT]].

## Caveat

The detected UniRef50 HGT signal is well below the pre-registered absolute Innovator-Exchange threshold. [src: gene_function_ecological_agora]

> - **The signal magnitude is small** — well below the absolute Innovator-Exchange threshold the Phase 1B hypothesis pre-registered. [src: gene_function_ecological_agora]
