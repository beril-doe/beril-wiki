# Metabolic overlap predicts PA14 inhibition but only partially

Across the 142-isolate analysis cohort, metabolic overlap with PA14 (weighted by PA14's substrate preferences) significantly predicts planktonic inhibition: r = 0.384, p = 2.3×10⁻⁶. [src: cf_formulation_design]

## Key figures

- **r = 0.384**: correlation of metabolic overlap with PA14 inhibition (scope 142-isolate analysis cohort) [src: cf_formulation_design]
- **p = 2.3×10⁻⁶**: significance of the correlation (scope 142-isolate analysis cohort) [src: cf_formulation_design]

## Evidence

> Across the 142-isolate analysis cohort, metabolic overlap with PA14 (weighted by PA14's substrate preferences) significantly predicts planktonic inhibition: **r = 0.384, p = 2.3×10⁻⁶**. [src: cf_formulation_design]

From the report [[summaries/cf_formulation_design__REPORT]].

## Caveat

The true out-of-sample predictive power of metabolic features is closer to 15% than 27%, so the effect size should be interpreted conservatively. [src: cf_formulation_design]

> The true out-of-sample predictive power of metabolic features is closer to 15% than 27%. This does not invalidate the qualitative conclusion — metabolic overlap is a statistically significant predictor (p = 2.3×10⁻⁶) — but the effect size should be interpreted conservatively. [src: cf_formulation_design]

## Other caveats in this report

- In the integrated PROTECT analysis of Pseudomonas aeruginosa PA14 inhibition, metabolic overlap explains only 27% of variance. [src: cf_formulation_design]
- The report states that repeated antibiotic courses used to treat cystic fibrosis airway infection select for resistance and disrupt the commensal microbiome. [src: cf_formulation_design]
- The report uses GTDB species taxonomy, which may differ from NCBI names. [src: cf_formulation_design]
- The PROTECT isolate collection reflects the typical cystic fibrosis airway microbiome plus deliberate oversampling of pathogens. [src: cf_formulation_design]
- Pseudomonas aeruginosa PA14's amino acid specialization is not universal among cystic fibrosis pathogens, suggesting protective formulations may need to be pathogen-specific. [src: cf_formulation_design]
