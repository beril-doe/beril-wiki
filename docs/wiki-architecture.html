Under the hood

No agent framework, no chat sessions — a plain Python pipeline making direct model calls.

enginePython scripts; each stage calls the model API directly (litellm → LBL's CBORG gateway)
modelsClaude Sonnet-class for synthesis — configurable per stage, swappable in one line
divisionthe model writes prose and JSON decisions only; code owns pages, links, figures, indexes
rulesone editorial contract file, injected into every call — change the rules, not the code
memoryevery input content-hashed; a rerun redoes only what changed
outputplain markdown in git → Quartz renders the static site; no database, no lock-in
