    How the agentic wiki compiler works

    The wiki is now compiled by a fixed schedule of small, bounded model jobs rather than a chain of Python scripts that each call a model. Every report becomes quoted evidence once, each record is routed to the pages it informs, and each page is written by Claude and checked by a GPT model before the host's own checks decide whether anything is published.

    Evidence is extracted once and flows to pages

    Extraction keeps exact quotes, and the host rejects any quote that is not verbatim in its report. Routing runs in parallel batches of 120 records, so planning no longer waits on itself, and a rerun replays every finished job from the ledger instead of paying for it again.

    Two model families check every page

    A page assigned more than 60 records is written in passes of up to 60, each reviewed on its own, so no single job holds hundreds of records. A pass that will not converge is dropped and listed for a person, and the rest of the page publishes.

    The scripts ran every stage; the runner pays only for what changed
